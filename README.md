# 잃어버린 것, 주운 것 — 축제 분실물 후보 찾기 (예시 서비스)

AI활용 의성군 서비스 개선 공모제안 경진대회 본선의 **발표자료 예시**에 쓰려고 운영진이 만든 서비스입니다.
본선 과제가 아닌 **예시용 과제**이며, 팀 이름은 "예시팀(운영진 제작)"입니다.

> 축제 운영본부 안내 담당자가, 분실 신고를 받는 순간에, 습득물 대장을 한 줄씩 넘겨 보는 일을 덜 하게 됩니다.

## 실행 방법

- 설치나 서버가 필요 없습니다. `index.html`을 브라우저로 열면 됩니다(휴대폰 화면에서도 됩니다).
- 공개 주소: https://uscaidev.github.io/lost-and-found-demo/
- 웹에 올릴 때는 아래 4개 파일을 한 폴더에 그대로 올리면 됩니다. 모두 상대 경로로 이어져 있어 하위 경로에서도 열립니다.

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 틀 |
| `style.css` | 화면 꾸밈(휴대폰은 한 줄, 넓은 화면은 두 줄) |
| `app.js` | 검색(문장 유사도)과 화면 동작 |
| `found-items.js` | 습득물 대장 데이터(가상 30건, JSON 형식) |

## 예시 과제와 제약사항

묘사를 입력하면 습득물 목록에서 맞을 만한 **후보**를 근거와 함께 보여 줍니다.

1. 같은 물건이라고 단정하지 않고 후보로만 보여 준다
2. 본인 확인 전에는 내주라고 안내하지 않는다
3. 묘사에 없는 특징을 덧붙이지 않는다

## 어떻게 찾는가 (AI 도구)

- **서비스 안의 검색**: 생성형 AI를 부르지 않습니다. 브라우저 안에서 도는 **문장 유사도 검색**입니다.
  묘사와 대장 문장을 낱말로 나눠 두 글자씩 자르고(글자 2-gram), TF-IDF 코사인 유사도로 순서를 정합니다.
- 화면에는 점수를 보여 주지 않고 **겹치는 말**을 근거로 보여 줍니다. 색이나 장소만 겹치는 습득물은 후보로 올리지 않습니다.
- 겹치는 말이 똑같은 후보가 2건 이상이면 고르지 않고 "가릴 수 없다"고 알립니다.
- "까만=검은", "핸드폰=휴대전화" 같은 같은말 표는 운영진이 직접 만들어 `app.js` 위쪽에 두었습니다.
- **개발**: Claude Code(생성형 AI 도구)로 코드·데이터·시험을 만들었습니다.
- 입력한 내용은 어디로도 전송되지 않습니다. 분실 신고 접수와 인계 기록은 **모의** 기능입니다.

## 데이터 출처

- `found-items.js`의 습득물 30건은 **전부 운영진이 지어낸 가상 데이터**입니다. 실제 축제·사람·물건과 관계없습니다.
- 사람 이름과 연락처는 넣지 않았습니다. 빈 칸은 화면에 "확인 필요"로 나옵니다(3건에 일부러 빈 칸을 두었습니다).
- 대장의 묘사는 조사를 빼고 메모하듯 적습니다(예: "검은색 반지갑. 곰돌이 열쇠고리 달림.").

## 알려진 한계

- 글자가 겹치는 것을 보므로 "반지"를 찾으면 "반지갑"이 후보로 나옵니다.
- 같은말 표에 없는 말(예: 상표 이름)은 다른 말로 봅니다.
- 사진으로 찾기, 습득물 등록 화면, 실제 대장·문자 연계, 생성형 AI 연결은 만들지 않았습니다.
